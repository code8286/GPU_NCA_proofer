# Stage 11: fresh-phase confirmation of the objective-specific diversity finding

Declared 21 October 2026 before fitting or scoring new confirmation models.
Stage 10's BOTH-objective primary failed; its weighted stratum passed 3/3 while
standard passed 1/3. Preserve that negative primary. This new study explicitly
tests the weighted hypothesis generated by that development result, using fresh
data and seeds. It is conditional confirmation on one fixed binary rule and one
new data split, not a new independent rule family or language-transfer study.

## Frozen data and models

complement split representatives conservatively joint-canonicalized; all v7
train/development/assessment classes; ALL v7 neighbor-flipped assessment classes;
and all 4096 v10 training classes. V8/V9 reuse these identities. Each joint class
contains phases under both complement and spatial involutions. Preserve all
historical inputs, fitted checkpoints, evidence and results intact.

Using seed 20261023, permute all 65536 states. First reserve 128 assessment
representatives AND each neighbor-flipped partner's joint class, skipping any
historical/reserved class. Then choose 64 development and 4096 training rows from
the same permutation with no reused class. This outcome-free construction makes
all 128 interventions eligible. Exclude their classes from training/development;
do not discard assessment cases after scoring. New splits are entirely disjoint
from historical classes, and from each other's entire joint orbits. There is no
claim of spatial-translation-disjointness. No outcome or complexity filtering.

The smaller cache is the exact first 512 rows of the larger coherent and shuffled
caches. Prefix shuffle seeds are data_seed+1,+2,+3 for train/development/assessment.
They preserve initial context, markers and each supervised-prefix patch histogram.
Both caches use the same held-out data. One new common split is shared by three
NEW initialization seeds 179,193,211; these are initialization replicates, not
three independently sampled data/rule cohorts.

Train ALL 24 models anew: 512/4096 rows × standard/weighted loss × coherent/prefix
shuffle × three seeds. Eight models within a seed start from identical saved

Each consumes 188000 input tokens and 168000 supervised targets. Total NEW work:

Uniform replacement sampling uses seed+101 and 4000 row draws/model. Freeze and
verify order digests, actual distinct exposure and observed row indices. Four

changes examples and repetition. Available rows are not all necessarily drawn.
Log unweighted development metrics every 100 steps without checkpoint selection.
Freeze all sources, inputs, reference hashes, initialized weights and orders
before training. Wait for ALL 24 final checkpoints before assessment.

## Decisions fixed before fitting

Primary confirmation: ALL three weighted coherent seeds must individually have:

1. Smaller-cache minus larger-cache native first-patch assessment NLL >=0.01.
2. Smaller-cache minus larger-cache neighbor-intervention NLL >=0.01.
3. Larger coherent checkpoint's full-trajectory frequency AND ordering advantages
   >=0.01, using the existing train-only frequency predictor and matched shuffle.

Apply the exact same criteria to standard loss, reported separately. The broader
both-objective claim passes ONLY if BOTH strata pass; retain every failure. The
weighted primary does not replace or relabel stage 10's failed broad primary.
These fixed all-seed criteria are not a significance test or estimated population
effect. Do not pool away seeds, change margins, extend training, select checkpoints
or introduce another treatment after observing scores. Accuracy, coherent versus
shuffle-trained gains and difference-of-gains remain descriptive, not extra gates.
A weighted pass alone establishes neither superiority over standard loss nor a
dynamics-specific cause, speedup or downstream transfer.

## Assessment and retained evidence

Use the unchanged v5 full-trajectory scorer, v9 short-prefix first-patch scorer
and v9 teacher-forced first-transition patch/marker scorer. Three initial and 24
final models yield 54 full coherent/shuffled cells, 108 coherent fit-probe cells
(512 anchor, first 512 extension rows, 64 development, 128 assessment) and 27
intervention cases with all 128 pairs. First-patch prefix exposes only the initial
frame plus next start marker. Flip initial cell (0,3), outside the target patch;
its correct target patch changes bit zero. Native/intervention correctness and
paired-both correctness remain distinct from aggregate trajectory accuracy.
Short/long first-patch losses must agree within 1e-5 with identical correctness.

Calibrate a separate frequency predictor per cache: prior from all training rows,
concentration selected on first 256, unchanged deterministic training-only policy.
Preserve both baselines, original per-query vectors, draw masks/subset statistics
(empty subsets null), final parameters/optimizer moments, costs and receipts.
Reopen every checkpoint in a separate invocation and reproduce all scores and
decisions with the same scorer; this is replay, not independent loss code or a
second fitting. No historical outcome is pooled into confirmation estimates.

## Interpretation and stopping boundary

Regardless of result, report both objectives and controls and retain all costs.
This tests an endpoint improvement at fixed exposure on a known binary rule, not
time-to-target learning acceleration, GraphNCA effects or unseen-rule transfer.
A failure remains a failure; no same-study retuning. A pass justifies planning
a separately frozen bridge to interacting categorical/random rules, whose own
readiness must pass before any language suite. Original random-rule checkpoints
remain unready. Any later language comparison still requires an eligible frozen
synthetic configuration, fresh paired cohorts and an identical full language
stage. No official language test, remote GPU, paid job, push or publication.
